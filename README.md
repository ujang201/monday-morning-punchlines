Entry for the [Monday Morning Punchlines](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc) bounty on make.fun ($5 reward).

## The joke

> Monday morning my alarm went off, took one look at me, and hit snooze on itself.

80 characters. The twist: the alarm clock — whose only job is to wake you —
gives up first and snoozes *itself*.

## How it works

`main.ts` writes that single fixed joke to `/output/entry.txt`. No network, no
randomness, no clock reads — every run produces byte-identical output, well
inside the 1–200 character gate.

Run it with:

```sh
node main.ts
```
